# Employee phone app guidance

- This is a planned phone-first employee interface. Employee roles, permitted information, and workflows remain to be confirmed.
- Treat employee identity and access as sensitive. Obtain only the data required for an approved task and enforce permissions through the shared server API.
- Do not expose owner settings or assume every employee can see all store information.
- Keep interaction patterns suitable for phone screens and unreliable connectivity where requirements call for it; do not promise offline behavior unless implemented.
