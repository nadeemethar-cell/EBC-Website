# Public website guidance

- This folder is the existing public Arabic-first, bilingual static catalog. Preserve its plain HTML/CSS/JavaScript behavior unless a requested change calls for a new stack.
- Keep image and stylesheet/script references relative to `website/` so the site can still be deployed as a static folder.
- Do not put credentials, private employee/store data, or owner controls in public client code.
- Do not turn the current email-draft request flow into an order submission or claim that requests are stored until a backend is implemented.
- Verify Arabic right-to-left and English left-to-right behavior when changing shared page layout.
